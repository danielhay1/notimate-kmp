# Specs

This repository uses a GitHub Spec Kit-style workflow:

- `.specify/memory/constitution.md`: project-wide principles and constraints.
- `specs/<number>-<feature>/spec.md`: requirements and acceptance criteria.
- `specs/<number>-<feature>/plan.md`: architecture and implementation plan.
- `specs/<number>-<feature>/tasks.md`: executable implementation checklist.

Before writing production code, update or create the relevant spec. Keep `spec.md`, `plan.md`, and `tasks.md` aligned as decisions change.
